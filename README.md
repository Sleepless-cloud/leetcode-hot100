# LeetCode Hot 100 刷题记录

个人刷题笔记仓库，记录 [LeetCode Hot 100](https://leetcode.cn/studyplan/top-100-liked/) 的思路、易错点与常用模板。

这是我个人在 2026 年上半年刷 Hot 100 的个人思路记录，记录一下个人的刷题心得。

语言以 Python 思路描述为主，偏个人向的记录。

## 如何使用

1. 从 [`notes/INDEX.md`](notes/INDEX.md) 按序号找题。
2. 打开 [`notes/hot100.md`](notes/hot100.md) 阅读对应条目的笔记。
3. 本地可按需追加代码文件（如 `solutions/`），本仓库当前以笔记为主。

## 目录结构

```text
leetcode-hot100/
├── README.md           # 本说明
├── .gitignore
└── notes/
    ├── INDEX.md        # 题目索引（100 题）
    └── hot100.md       # 完整刷题笔记
```

## 进度说明

- 覆盖序号 【1】–【100】，共 **100** 道笔记。
- 开头含若干通用小技巧（如索引与 `range` 的对应关系）。
- 笔记来源于个人学习过程，表述以实用为主，欢迎指出笔误。
